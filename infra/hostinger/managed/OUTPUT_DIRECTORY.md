# Event Control Hostinger output directory

For the managed Hostinger Event Control Web App, use:

```text
Build command: pnpm run build
Package manager: pnpm
Output directory: .hostinger-output
```

The Control Web workspace build creates `.hostinger-output` as a portable production app root. It contains the built `.next` directory plus a production `node_modules` generated by `pnpm deploy`, so Hostinger's generated top-level `server.js` can resolve `next` after copying the output into its `nodejs` runtime directory.
